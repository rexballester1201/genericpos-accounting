3Keeping it true

These files are built, not hand-edited. The prose for seven of them lives in docs/manual-src/*.mjs; the User's Guide is rendered from docs/guide/*.md, the same sixteen chapters the Help screen reads, so the printed guide and the in-app guide can never disagree; the audit is the working paper as issued.

node docs/build-docs.mjs     # docs/manual-src + docs/guide → docs/manual/*.html
node docs/build-guide.mjs    # docs/guide/*.md → help/guide.json (the Help screen)

Version

Version 1.0, issued 20 September 2026, against branch build/accounting. Change the code and these do not follow by themselves — rebuild them, and raise the version in docs/build-docs.mjs when what they say changes.

Not on the running site

docs/ is refused by .htaccess, which is what keeps the source and the schema off the web. Read this set from a checkout of the repository, not from the installed system. The user's guide is in the app — Help, on the menu — because it is published there as data rather than as files.
